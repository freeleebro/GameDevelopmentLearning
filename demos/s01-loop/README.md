# s01-loop · 手写游戏循环

S01 的练习项目。**硬性约束：不使用任何游戏引擎**，只有原生 canvas + `requestAnimationFrame`。

## 怎么跑

```bash
cd demos/s01-loop
npm install
npm run dev      # 打开终端提示的地址（默认 http://localhost:5173）
```

## 目录与分工

| 文件 | 谁写 | 内容 |
| --- | --- | --- |
| `index.html` | 已给 | 800×600 画布，尺寸与 demo1 一致，方便对照 |
| `src/main.ts` | 已给 | 接线：画布 → 世界 → 循环，无逻辑 |
| `src/loop.ts` | **你写** | 主循环：时间 → 更新 → 绘制 → 预约下一帧 |
| `src/world.ts` | **你写** | 世界状态与每个逻辑步的变化（不碰 canvas） |
| `src/render.ts` | **你写** | 把世界画出来（不改状态） |

## 要证明什么

1. 方块能动，屏幕不拖影；
2. 能说清一帧里发生了什么、顺序为什么是这个顺序；
3. 能解释「为什么不能用 `for(;;)` 做游戏循环」。

## 三个必答问题（T1）

- 不 `clearRect` 会怎样？画面为什么是那个样子？
- 用 `for (;;) { }` 代替 rAF 会发生什么？浏览器会怎样？
- rAF 回调的参数是什么？单位和起点是什么？
